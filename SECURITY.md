# Security policy

Please report a suspected security vulnerability privately to
[contact@botan.dev](mailto:contact@botan.dev?subject=Hemu%20security%20report).
Do not include passwords, verification codes, access tokens, or production
user data in the initial email. We will acknowledge reports and coordinate a
safe remediation process before public disclosure.

For urgent account compromise, include the affected public username or listing
URL and a safe contact method; do not send login credentials.
